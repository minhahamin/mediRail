# 응급 징후 처리

## 시스템의 동작 (알고 있어야 하는 것)

- **환자가 쓴 채팅**에 응급 키워드가 있으면 코드(`guardrails.detect_emergency`)가 **LLM 호출 없이 즉시 119를 안내**한다. 자살·자해 언급이면 자살예방 상담전화 109도 안내한다.
- **의료진의 대화**는 임상 메모("환자가 흉통 호소")를 막으면 안 되므로 차단하지 않는다. 대신 응급 징후를 **놓치지 않는 것**이 이 스킬의 역할이다.

## 의료진과의 대화에서

1. 문진·진료 메모에 응급 징후가 있으면 요약의 **맨 위**에 `⚠️ 응급 의심 소견`으로 표시한다.
2. 원문 표현을 그대로 옮기고, **진단하거나 중증도를 단정하지 않는다** ("심근경색입니다" 금지).
3. "즉시 의사 확인이 필요합니다"라고 한 줄 덧붙인다.
4. 응급 징후가 있는 환자의 **예약을 미루도록 권하지 않는다.** 판단은 의사가 한다.

## 응급 징후 목록

| 범주 | 예 |
|---|---|
| 심장 | 가슴을 쥐어짜는 통증, 왼팔·턱으로 뻗는 통증, 식은땀 |
| 뇌졸중 | 한쪽 팔다리 힘 빠짐, 말이 어눌함, 얼굴 처짐, 갑작스러운 시야 이상 |
| 호흡 | 숨쉬기 힘듦, 입술이 파래짐 |
| 의식·경련 | 의식 없음, 쓰러짐, 경련·발작 |
| 아나필락시스 | 벌레·음식·약 뒤 두드러기 + 목·혀가 붓거나 숨이 답답함 |
| 출혈 | 멈추지 않는 출혈, 토혈, 다량의 혈변 |
| 자해 | 죽고 싶다, 자해, 사라지고 싶다 |

## 한계 (알려진 것)

응급 감지는 **재현율 우선**이라 부정 표현("흉통은 없어요")도 감지될 수 있다. 안전한 방향의 오류라 감수했다.
