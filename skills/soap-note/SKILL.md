# SOAP 노트 초안 작성

**AI는 초안만 만든다.** 확정(승인)은 의사가 화면에서 직접 한다. 승인 도구는 존재하지 않는다.

## 절차

1. 환자를 확인한다. 화면에서 선택된 환자 id가 있으면 그것을, 없으면 사용자가 말한 환자를 쓴다.
2. `get_encounter(patient_id)`로 최신 진료 메모를 조회한다.
3. 메모를 네 항목으로 나눈다.

| 항목 | 넣는 것 | 넣지 않는 것 |
|---|---|---|
| **S** 주관적 | 환자가 말한 증상·경과·주호소(CC) | 의사의 판단 |
| **O** 객관적 | 측정값·검사·진찰 소견 (체온, 혈압, SpO2 등) | 환자의 호소 |
| **A** 평가 | 의사 메모의 판단을 **"의사 확인이 필요한 의심 소견"** 으로 표현 | **확정 진단** |
| **P** 계획 | 치료·교육·재방문·악화 시 지침 | 메모에 없는 처방·용량 |

4. `save_soap_draft`로 **초안 저장**한다.
5. 저장 후 네 항목을 보여주고 "초안입니다. 검토 후 승인해 주세요"라고 안내한다.

## 규칙

- 원문에 없는 수치·소견·계획을 만들지 않는다. 없으면 "기록 없음"으로 쓴다.
- A는 "…의심", "…가능성"으로 쓴다. "확진", "진단합니다", "처방합니다" 표현은 저장이 거부된다.
- 수치는 원문 그대로 옮긴다 (37.9, SpO2 98%, 152/96).
- 환자 이름은 답변에서 필요할 때만 쓴다.

## 예시

메모: `CC: 기침 5일. 열 37.9, 인후 발적, 폐음 깨끗, SpO2 98%. 급성 상기도감염 의심, 수분/휴식, 3일 후 재방문, 악화 시 내원.`

- **S** 기침 5일
- **O** 체온 37.9, 인후 발적, 폐음 깨끗, SpO2 98%
- **A** 급성 상기도감염 의심 (의사 확인 필요)
- **P** 충분한 수분·휴식, 3일 후 재방문, 악화 시 내원
