# 문진 요약

## 절차

1. 환자를 확인한다 (화면에서 선택된 환자 id 또는 사용자가 말한 환자).
2. `get_patient_intake(patient_id)`로 최신 문진 원문과 알레르기·복용약을 조회한다.
3. 아래 형식으로 요약한다.

```
[응급 징후가 있으면] [응급 의심 소견]: (원문 표현 그대로) — 즉시 의사 확인 필요
주호소:      한 줄
현병력:      시작 시점, 양상, 경과, 동반 증상 (없다고 한 것도 기록: "기침 거의 없음")
과거력·복용약: 기저질환, 복용 중인 약(용량 포함)
알레르기:    없으면 "없음"
```

## 규칙

- **원문에 없는 정보를 추가하지 않는다.** 없는 항목은 "기록 없음"이라고 쓴다.
- 수치·기간·약 이름은 원문 그대로 쓴다 (38.2도, 3일 전, 암로디핀).
- **부정 소견도 옮긴다** ("구토 없음", "수술력 없음").
- 진단·감별을 하지 않는다. "…로 보인다"는 표현을 쓰지 않는다.
- **응급 징후**(흉통, 호흡곤란, 의식저하, 편측 마비·말 어눌, 경련, 심한 출혈, 목이 붓는 알레르기 반응, 자해·자살 생각)가 원문에 있으면 요약 **맨 위**에 눈에 띄게 표시한다. 다른 내용에 묻히게 하지 않는다.
- 문진에 알레르기·복용약이 있으면 항목을 빠뜨리지 않는다 (처방 안전의 핵심이다).

## 예시

원문: `3일 전부터 목이 아프고 열이 38.2도까지 올랐다. 기침은 거의 없고 침 삼키기 힘들다. 암로디핀 복용 중이고 페니실린 알레르기가 있다.`

- **주호소** 인후통, 발열
- **현병력** 3일 전 시작, 최고 체온 38.2도, 연하곤란, 기침 거의 없음
- **과거력·복용약** 암로디핀 복용 중
- **알레르기** 페니실린
