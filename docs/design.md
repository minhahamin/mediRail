# MediRail 프론트 스타일 가이드

레퍼런스: 세이지 그린 스티커/문구 스타일 (레트로 데스크탑 창 + 다이어리 소품)

## 토큰
- 배경: #F4F5F2 (off-white) + 격자/도트 패턴
- 메인 그린: #8FB08C / 진한 아웃라인: #3E6B4A / 연한 그린: #DCE8D8
- 카드: 흰색 + 2px 진녹색 아웃라인 + 오프셋 하드 섀도(4px 4px 0 #8FB08C), 큰 라운드(14~18px)
- 경고/응급: 레퍼런스 톤에 맞춘 뮤트 코랄 (#D98A7B) — 그린 계열과 구분되는 유일한 강조색

## 컴포넌트 모티프
- 창(Window): 상단 그린 타이틀바 + X 버튼 → 메인 패널 / 채팅 창
- 메모장(Notepad): 점 목록 + 밑줄 → 문진 요약, 체크리스트
- 스파이럴 노트: 상단 링 → SOAP 노트 카드
- 마스킹 테이프 / 핀: 카드 모서리 장식 → 출처(인용) 카드에 핀 아이콘
- 플레이어 바: 하트 아이콘 + 컨트롤 → 예약/진행 상태
- 브라우저 창 + 격자: 문헌 검색 결과 영역
- ✦ 반짝이: 포인트 장식

## 역할별 구분
환자 / 의사 / 간호사 / 원무 — 같은 톤 안에서 타이틀바 아이콘과 명도로 구분.
